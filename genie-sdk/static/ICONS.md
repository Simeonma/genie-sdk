## 0. 验收（先看这条）

- **好看是第一验收项**，不是"能认出"。难看就是不合格，尺寸/规范都要让步。
- **26px 能认、22px 不掉细节**：树里 22px、工具栏 26px、几何 28px，都按这个查。
- 一律**透明底**、无文字、无投影到背景、无卡片外的容器。
- 新图标先看这一条：**和现有 34 枚放一起，像不像同一套软件**。

## 1. 两套语言（不要混着用）

| 语言 | 用在哪 | 特征 |
|---|---|---|
| **3D 渲染** | 仿真对象：材料 / 监视器 / 源 / 几何 | 磨砂玻璃、族色、柔和棚光、细高光棱 |
| **2D 裸记号** | 文件 / 控制 / 视图 | 浅色线稿 + 极浅填充、无卡片底、单色线条 |

规矩来自 `style.css`：**按钮无框无底**（去掉"个个带盒"的格栅感），所以控制与视图
一律画成裸记号，不给它们加卡片底。

## 2. 配色

- 控制与视图：**只用界面 accent `#1F62B0`**（界面主色，见 `style.css --accent`）。
  「图标自己一套蓝」是错的——会和界面打架。
- 对象族：各族自己的色（材料青绿 / 监视器深蓝 / 源琥珀 / 几何靛紫），族内必须一致。
- 辅助色只允许一处强调（例如剖面的暖色下层），不要第二种装饰色。

## 3. 尺寸

`previewEl()` 出 `img.pv-img` 或内联 `svg`，尺寸全在 `style.css` 一处：

| 场景 | 尺寸 |
|---|---|
| 几何按钮 `#tb-geo-btns` | 28 |
| 材料 / 源 / 监视器 / 文件 / 视图按钮 | 26 |
| 树 `.tree-ic.tree-pv` | 22 |
| 卡片头 `.obj-preview` | 40 |
| 空态 `.empty-ic` | 34 / 44 |
| 兜底 `.pv-img` | 26 |

新增容器**必须**在 `style.css` 里补一条同尺寸规则，否则 `<img>` 会按原生 160px 撑开。

## 4. 素材从哪来

- 34 枚 PNG：定型清单见 `local/icon-preview/frozen/manifest.json`（本机，不进仓）。
- 8 枚 SVG 回退：`layout` / `params` / `domain` / `view_proj` / `view_wire` / `view_ruler`
  / `view_grid` / `view_shot`——还没有成品素材，继续用旧线条图。
- 缺图处置：`ellipse_z` 直接复用 `cylinder` 的素材（同一个概念，不画两枚）；
  `domain` 暂不做专属图（站长判：以后可能不在 GUI 出现）。

## 5. 接线纪律

- **一条路**：`previewEl(key)` 是唯一入口；有 PNG 出 `<img>`，没有才回退 SVG，
  彻底未知的 key 退到 `box`。不要在各模块里自己拼图片或 SVG。
- **死 key 不许复活**：`agent` / `file_script` / `mat_library` / `view_labels` 已删；
  `mon_mode` 有图无 API（等 `_MON_TYPES` 加 mode）。
- 新增 key 要在 `previews.js` 的 `ICON_SRC` 里登记，并把素材放进 `assets/icons/`。
- 改素材只换文件，**不要在代码里对 PNG 做二次改色**——配色必须落在素材本身。

## 6. 不许

- 不许用"看起来像图标"的临时图形占位（宁可回退 SVG）。
- 不许为某个尺寸单独做一套图（一套素材 + CSS 尺寸解决）。
- 不许在图标里写字、加边框卡片、加发光雾。
